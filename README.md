# img2VTF

A free, in-browser tool for converting images and animated GIFs into Team Fortress 2 sprays (.vtf).

**Use it:** https://garracal.github.io/img2VTF/

Everything runs in your browser. Your images are never uploaded anywhere.

## Quick start

Drop in an image, position it on the canvas, and click **Export VTF**. In TF2, go to **Options → Multiplayer → Import Spray** and choose the file.
